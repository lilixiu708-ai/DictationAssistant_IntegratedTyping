## 听写流程

1. 先使用原软件编辑词表（每行一条），或从 `.docx` 导入。空白行忽略，重复词条保留。需要先乱序，可点击「打乱顺序」或 `Ctrl+Shift+R`。
2. 设置原程序右侧「自动播报次数/词」及「自动播报间隔/秒」，例如 2 次和 2 秒。选好英文语音、音量和语速。
3. 打开原窗口「插件 → 同步打字练习」或 `Ctrl+Shift+T`。程序在后台读取并核对当前词表，成功后显示「已读取 实际数量 / 理论数量 条」，例如「已读取 40 / 40 条」；再设置每词打字时限（默认 10 秒，可选 1–300 秒）以及是否忽略大小写。
4. 点击「开始练习」后，从第一次播放到最后一次语音结束，包括重复间隔，都显示 **「播放中」**，不露出答案或打字框。
5. 最后一次**实际音频播放结束**后才出现打字框，并开始计时。倒计时上方不再显示下划线占位条；最后一次播报结束后不再额外等待 2 秒。
6. 按 Enter 提前记录；超时自动记录当前输入，空白也可记录。每个词**不立即显示对错**。
7. 顶部进度条显示已完成的词条数量。全部词条结束后统一显示正确率，成绩区逐词列出正确词条、你的输入和结果；可滚动查看全部记录，并导出 UTF-8 BOM 的 CSV。滚动成绩时，顶部摘要和底部导出、关闭按钮保持可见。

例：`Monday` → `[播放中 1/2]` → `[等待 2 秒，仍显示播放中]` → `[播放中 2/2]` → `[输入框 + 10 秒]` → `[只记录]` → 下一个词。

准备页的介绍文字放大为 18 号并居中，倒计时和本轮完成进度条在开始前隐藏；开始练习后保留进度条，用于查看已完成数量。

## 翻译提示与提前翻译

R5 与 R6 的宿主词表都按每行一条填写原词或短语，作为播报内容和正确答案；不要在宿主词表中追加翻译。练习准备页提供「录入／提前翻译」，打开后按“原词 + Tab + 译文”两列编辑，也可以从电子表格复制两列粘贴。原词须保留当前词表中的大小写和标点；重复原词共用一份译文，译文留空可删除该词的提示。

点击「保存」后，译文写入本机文件，其他词表已保存的翻译会保留：

```text
%APPDATA%\DictationAssistant\Plugins\SynchronousTyping\translations.json
```

「显示翻译提示」默认关闭，可在练习时随时勾选或取消。提示只在每词全部播报结束后的打字阶段显示；没有译文的词条不显示提示。显示与隐藏均不改变播报内容、正确答案或评分规则。手动录入与查看已保存译文不需要网络或 API 密钥。

已发布的插件 1.1.0 / 1.2.0 支持 **DeepL API Free / Pro**；1.3.1 的新增服务见下一节。个人配置仅在本机程序中输入和管理，已有密钥不会回填显示。完成对应版本的配置后，在准备页选择 **英译中 / 中译英**，点击「翻译缺失项」才将缺失项的原词发送到当前服务；已有译文保留，结果校对后保存。配置、切换或打字均不触发翻译。

本次翻译界面已在 Linux 虚拟图形会话中核对：录入与保存、重新打开后恢复、打字时显示/隐藏提示、缺少密钥时的提示，以及原词判分与结算文字删除。两词练习使用本地 WAV 和 SDL dummy 音频输出，均按原词判为正确；未验证真实扬声器。API 设置窗口已核对空密钥校验、掩码输入、临时使用不产生密钥文件，以及再次打开不回填密钥；未向 DeepL 发送测试密钥。Windows DPAPI 保存及跨机器/账户拒绝读取、真实 DeepL 鉴权翻译仍须实机验证；构建通过不代表系统加密或外部服务已验证。

## 插件 1.3.1：常见翻译 API（待发布）

1.3.1 沿用下节的多绑定与首选项流程，在「配置… → 新建绑定」中选择服务，窗口会显示对应字段和帮助。接入对象是各服务商的**官方 API 账户**，须开通对应服务及调用权限，并受其额度和费用规则约束；网页翻译账号、Cookie 或免费网页地址不能替代接口凭据。

| 服务类型 | 主凭据 | 附加密钥 | 区域 |
| --- | --- | --- | --- |
| DeepL API Free / Pro | API 密钥 | 无 | 无 |
| 必应 / Microsoft Translator（Azure） | 订阅密钥 | 无 | 按 Azure 资源要求填写；区域或多服务资源通常需要 |
| Google Cloud Translation Basic v2 | API 密钥 | 无 | 无；须启用 Basic v2 服务并允许该密钥调用 |
| 百度翻译开放平台 | APP ID | 密钥 | 无 |
| 有道智云 | 应用 ID（AppKey） | 应用密钥（AppSecret） | 无 |
| 腾讯云机器翻译 TMT | SecretId | SecretKey | 必填，默认 `ap-guangzhou` |
| 阿里云机器翻译 | AccessKey ID | AccessKey Secret | 必填，默认 `cn-hangzhou` |
| 火山引擎机器翻译 | Access Key ID | Secret Access Key | 必填，默认 `cn-north-1` |

以上共 8 类服务、9 个可选类型，DeepL 分为 Free 与 Pro。区域须与账户的服务开通位置及权限匹配。保持同一服务类型编辑时可留空沿用已有凭据；更换类型时重新填写该服务要求的凭据。密钥仅在本机程序输入，Windows 加密绑定与会话使用规则不变，机器标识不会发送给翻译服务。

本次只更新同步打字插件；R6 本体、Word 1.0.1 及已发布的 1.2.0 保留。各服务真实账户鉴权及在线翻译尚未验证，不能把构建或窗口检查写成所有服务已实测可用。

## R6 / 插件 1.2.0：多绑定与首选项

本节适用于已发布的宿主 `4.0.0-typing.6` 与插件 `1.2.0`。仍只接入已有的 **DeepL API Free / Pro**，可为不同账户建立多个命名绑定，没有新增其他翻译服务。

1. 无需先打开词表，从「插件 → 插件管理…」找到同步打字插件，点击该插件的「配置…」。
2. 在「翻译引擎配置」中选择「新建绑定」，填写名称、服务类型与密钥，点击「添加绑定」。修改已有绑定时，密钥不会回填；保持相同服务类型可留空沿用，更换服务类型须重新填写。可修改或移除绑定。
3. 选择一个绑定并「设为首选」。这些操作先修改窗口草稿；Windows 点击「保存配置」后写入整份加密配置，或选择「仅本次使用」应用至当前程序会话。取消则保留原配置。首选项用于之后新打开的翻译准备页。
4. 在练习的「录入／提前翻译」准备页，用「本次翻译引擎」选择此次要用的绑定。此处切换不修改首选项；「管理翻译引擎…」打开同一套配置，明确保存或应用后与插件管理共享。
5. 选择翻译方向，点击「翻译缺失项」后才请求当前绑定的服务，校对结果后「保存翻译」。配置、切换引擎和开始打字均不触发翻译；已有译文仍可离线显示。

Windows 保存的 `translation-api.json` 将整份绑定列表、名称及首选项经 DPAPI 加密，并绑定本机与当前账户；系统加密不能防止已控制当前账户或程序进程的软件读取使用中的密钥。其他平台仅支持「仅本次使用」，配置保留到程序退出，关闭准备页后重新打开仍可使用。移除全部绑定后保存会删除本机持久配置。

同一 Windows 账户和机器上的 R5 单绑定文件可读取为一个绑定；只读打开不会改写旧文件，明确「保存配置」后才写入新格式。升级前保留旧版与数据备份，不将旧版程序能否读取新格式视为已验证行为。

本轮 Linux 图形验证已核对无词表打开配置、两个命名绑定与首选项、重新打开保留会话配置、已有密钥不回填、更换服务类型时的空密钥校验、取消草稿保留原配置，以及准备页局部切换与共用管理入口。移除全部引擎后自动翻译禁用，手动两列译文仍可保存和恢复；配置、练习及程序正常关闭，程序重启后临时绑定清空，未产生密钥配置文件或含测试凭据的日志。Windows DPAPI、R5 文件迁移、完整边界校验和真实翻译尚未验证；详细记录见[验证清单](同步打字验证清单.md)。

### R5 / 插件 1.1.0 的旧入口

R5 使用「录入／提前翻译 → 翻译 API 设置」管理一个 Free 或 Pro 绑定。Windows 可「保存并使用」本机与当前账户绑定的加密密钥，或「删除本机绑定」；「仅本次使用」只保留到该编辑窗口关闭。其他平台仅支持临时使用。R6 的多绑定操作以上节为准，旧版程序读取 R6 新格式的行为未经验证。

## 后台读取与异常日志

理论数量来自进入练习时当前编辑器的词表快照，按非空行统计，重复词条分别计数；实际数量是练习插件成功读取并核对的词条数。这项检查核对当前词表到练习的传递，不检测原 DOCX 在导入之前或导入过程中是否已经缺词；原文完整性仍需在导入预览中核对。

读取完成前不能开始练习。发现数量不符、词条无效或读取失败时，程序禁用「开始练习」，显示错误并自动尝试保存 crash log。Windows 日志目录为：

```text
%APPDATA%\DictationAssistant\Plugins\SynchronousTyping\CrashLogs
```

日志记录失败阶段、实际和理论数量、失败词条的序号（从 1 开始，能够定位时）、版本及异常详情，保留最近 20 份。程序不主动附加整份词表或作答内容；第三方异常详情仍可能包含词条或文件路径，分享日志前请自行检查。

## 本机 Windows 构建（.NET 10 SDK、Python 3.11+）

解压源码，双击 `build-windows-typing.cmd`。构建成功后使用 `artifacts/Windows-x64/DictationAssistant.App.exe`，也会生成 `artifacts/DictationAssistant_IntegratedTyping_Windows_x64.zip`。

首次还原 NuGet 依赖必须联网。本地若没有 SDK，脚本会明确提示使用 GitHub Actions；它不会调用 PowerShell，也不会假装完成编译。

新版不再携带 BASS。本地音频资源可使用 WAV（PCM/浮点）、MP3/MPEG 或 AIFF；Windows 上其他格式依赖系统 Media Foundation 解码器，不能保证每台机器都有 FLAC、AAC、Opus 或 APE 支持。升级后应重新核对现有音频资源，无法解码时会尝试所选语音引擎。

## 便携包与插件布局

```text
DictationAssistant.App.exe
DictationAssistant.App.dll
DictationAssistant.Plugin.Abstractions.dll
Plugins/
  DocxVocabulary/
    plugin.json
    DictationAssistant.Importers.Docx.dll
    （其他依赖）
  SynchronousTyping/
    plugin.json
    DictationAssistant.Practices.Typing.dll
    （其他依赖）
```

同步打字为**独立的 .NET DLL 侧载插件**，不是浏览器应用，不能把 DLL 直接放入没有练习插件接口的旧 EXE。修改后的宿主会加载 `kind=practice`；原来的 `IDocumentImporter` Word 接口保持兼容。插件管理可以查看加载失败原因。第三方插件运行时拥有与程序相同的权限，**不是安全沙箱**。

独立插件更新时先关闭程序，再以完整的 `SynchronousTyping/` 或 `DocxVocabulary/` 目录替换 `Plugins/` 下对应目录并重启；不要只复制主 DLL。同步打字 **1.2.0 要求宿主功能级别 4（R6）**，旧版 **1.1.0 要求功能级别 3（R5）**；不可把新插件单独放入 R5。译文与加密设置保存在用户 AppData，替换插件目录不会删除它们，升级前仍应备份。Word 导入 1.0.1 复用原独立发行，不覆盖资产。
