# DictationAssistant 4.x — 同步打字 DLL 插件（Windows x64）

**交付状态：完整源码与自动化构建方案；尚未产生或验证集成后的 Windows EXE。** 当前构建容器没有 .NET 10 SDK，外部下载被限制。不要把旧版 EXE 或以前的本地网页当作已预装同步打字 DLL 的成品。

本项目以原版 `DictationAssistant`（C# + Avalonia）为基础，保留原窗口、SDL 音频播放器、Word 导入插件和随机重排，在插件接口中新增独立 `SynchronousTyping` 练习插件。原项目许可证 AGPL-3.0-or-later 及声明保留。

## 你要求的听写流程

1. 先使用原软件编辑词表（每行一条），或从 `.docx` 导入。空白行忽略，重复词条保留。需要先乱序，可点击「打乱顺序」或 `Ctrl+Shift+R`。
2. 设置原程序右侧「自动播报次数/词」及「自动播报间隔/秒」，例如 2 次和 2 秒。选好英文语音、音量和语速。
3. 打开原窗口「插件 → 同步打字练习」或 `Ctrl+Shift+T`，设置每词打字时限（默认 10 秒，可选 1–300 秒）以及是否忽略大小写。
4. 开始后出现模态练习窗口：从第一次播放到最后一次语音结束，包括重复间隔，都显示 **「播放中」**，不露出答案或打字框。
5. 第 2 次**实际音频播放结束**后才出现如下下划线和打字框，并开始计时。最后一次播报结束后不再额外等待 2 秒。
6. 按 Enter 提前记录；超时自动记录当前输入，空白也可记录。每个词**不立即显示对错**。
7. 顶部进度条显示已完成的词条数量。全部词条结束后统一显示正确率，成绩区逐词列出正确词条、你的输入和结果；可滚动查看全部记录，并导出 UTF-8 BOM 的 CSV。滚动成绩时，顶部摘要和底部导出、关闭按钮保持可见。

例：`Monday` → `[播放中 1/2]` → `[等待 2 秒，仍显示播放中]` → `[播放中 2/2]` → `[______ + 输入框 + 10 秒]` → `[只记录]` → 下一个词。

## 不通过 PowerShell 获取可执行成品（推荐：GitHub Actions）

已提供 `.github/workflows/build-typing-windows.yml`。将**解压后的源码树本身**发布到你自己的 GitHub 仓库（不能只上传 ZIP 文件），使用 GitHub 的 Actions 服务编译，不需要在 Windows 电脑上安装 SDK，也不需要运行 PowerShell。可用 GitHub Desktop 图形界面发布随包附带的 Git 仓库：

1. 解压 `DictationAssistant_IntegratedTyping_GitHubReady.zip`。
2. GitHub Desktop → `File → Add local repository...`，选择解压得到的源码目录（其中有 `.git` 文件夹）。
3. 点击 `Publish repository`，发布到你的 GitHub 账户。私有仓库亦可，但需要账户有 GitHub Actions 可用额度。不要发布自己的其他私人文件。
4. 打开该仓库的 `Actions → Windows desktop app with preinstalled typing plugin → Run workflow`。如果 push 到 `main` 后自动开始，也可以直接查看该次运行。
5. **只有工作流全部绿色完成**后，打开该运行页面的 `Artifacts`，下载 `DictationAssistant-Integrated-Typing-Windows-x64`，解压其中的 `DictationAssistant_IntegratedTyping_Windows_x64.zip`。
6. 将该 ZIP 完整解压到 Windows 文件夹，双击 `DictationAssistant.App.exe`。这是带 .NET 运行环境和两个 DLL 插件的桌面程序，不打开网页。

GitHub Actions 如果显示 `failed`，请把错误日志发来继续修复。**在绿色完成之前不能保证源码能编译运行**。CI 会自动测试重复播放等待与判分，并核对打包后的两个 DLL 与 `plugin.json`。

## 已有 .NET 10 SDK 的 Windows 电脑（纯 CMD，无 PowerShell）

解压源码，双击 `build-windows-typing.cmd`。构建成功后使用 `artifacts/Windows-x64/DictationAssistant.App.exe`，也会生成 `artifacts/DictationAssistant_IntegratedTyping_Windows_x64.zip`。

首次还原 NuGet 依赖必须联网。本地若没有 SDK，脚本会明确提示使用 GitHub Actions；它不会调用 PowerShell，也不会假装完成编译。

## 成品布局（CI 成功后才会生成）

```text
DictationAssistant.App.exe
DictationAssistant.App.dll
DictationAssistant.Plugin.Abstractions.dll
Plugins/
  DocxVocabulary/
    plugin.json
    DictationAssistant.Importers.Docx.dll
    （其他依赖）
  SynchronousTyping/
    plugin.json
    DictationAssistant.Practices.Typing.dll
    （其他依赖）
```

同步打字为**独立的 .NET DLL 侧载插件**，不是浏览器应用，不能把 DLL 直接放入没有练习插件接口的旧 EXE。修改后的宿主会加载 `kind=practice`；原来的 `IDocumentImporter` Word 接口保持兼容。插件管理可以查看加载失败原因。第三方插件运行时拥有与程序相同的权限，**不是安全沙箱**。
