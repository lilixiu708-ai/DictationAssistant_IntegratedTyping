## 原 NuGet DLL 纳入 DNG 的证据

- 精确 SkiaSharp 提交 `9699cdf046a989423a5e5eca68e7fd813486d81c` 的 [Windows 构建脚本原文](https://raw.githubusercontent.com/mono/SkiaSharp/9699cdf046a989423a5e5eca68e7fd813486d81c/native/windows/build.cake) 第 42、44 行分别启用 `skia_use_dng_sdk=true`、`skia_use_piex=true`。
- 对应 Skia `4bed689c9c9eb77a120c6a9d54af6a572c85d1c2` 的 [`BUILD.gn` 原文](https://raw.githubusercontent.com/mono/skia/4bed689c9c9eb77a120c6a9d54af6a572c85d1c2/BUILD.gn) 第 1022–1036 行将 RAW codec 与 DNG 依赖连接，并纳入 `SkRawCodec.cpp`。这与固定 `DEPS` 链相互印证。
- 对 `SkiaSharp.NativeAssets.Win32 2.88.9` 中 Windows x64 `libSkiaSharp.dll` 的直接字节检查记录了 101 项 DNG/piex 实现和 RTTI 字符串，包括含 `PerformAreaTask@SkDngHost` 的 RTTI 项、`.?AVdng_negative@@` 与 `.?AVdng_render_task@@`；不是仅因通用通知提到了 DNG 就推定纳入。二进制 SHA-256 为 `9a0d95e8caaa852c70d085af6a40a744242172ad9ea3fd6bc7599875a8a1dbcd`；完整文件偏移、PE RVA、字符串和检查方法见[固定证据 JSON](../third-party/evidence/SkiaSharp-2.88.9-win-x64-DNG-binary-evidence.json)。未执行 Windows 运行时验证，不据此声称已完整反编译或穷尽所有内嵌组件。

这些证据针对上述固定哈希的原 NuGet DLL，确认其 DNG 分发条件，不表示已验证的新替代 DLL 仍含 DNG。新 DLL 的构建提交、哈希及无 DNG 检查记录见[原始构建证据](../third-party/evidence/skia-no-dng-2.88.9-win-x64/README.md)；旧归属保留用于溯源，不把新替代的成功写成旧 DLL 已获得额外授权。

## Avalonia 中 MS-PL 部分的组合核对

固定 `Avalonia@37fbd9655cc581ff5b1c6b1fb1be4e3118c889d0` 中 19 个 C# 源文件显式保留 Microsoft/MS-PL 头，例如 [AutoCompleteBox.cs](https://github.com/AvaloniaUI/Avalonia/blob/37fbd9655cc581ff5b1c6b1fb1be4e3118c889d0/src/Avalonia.Controls/AutoCompleteBox/AutoCompleteBox.cs#L1)、[Calendar.cs](https://github.com/AvaloniaUI/Avalonia/blob/37fbd9655cc581ff5b1c6b1fb1be4e3118c889d0/src/Avalonia.Controls/Calendar/Calendar.cs#L1)。实际 `Avalonia.Controls.dll` 版本 `11.3.12.0`、SHA-256 `748dcbdf46bf38ad956bf9592a450cc70642e8c79c8456522d63b61a5cb31023` 含 22 个相关 TypeDef；AutoCompleteBox、Calendar、CalendarDatePicker 分别有 133、129、81 个带 IL 的方法。App 对它有直接 AssemblyRef，不能仅按历史 NOTICE 或旁置聚合处理。完整[核查记录](../third-party/evidence/avalonia-mspl-11.3.12/REVIEW.md)、[源头索引](../third-party/evidence/avalonia-mspl-11.3.12/source-header-index.json)和[程序集证据](../third-party/evidence/avalonia-mspl-11.3.12/actual-managed-payload-metadata.json)已入库。

[原 MS-PL §3(D)](../LICENSES/third-party/avalonia-11.3.12/NOTICE.md#silverlight-toolkit) 要求源码分发继续使用该许可，二进制分发采用符合该许可的许可。这不等于原源代码已有 AGPL 双授权或链接例外；本次未找到针对这些特定部分的授权依据。保留原通知但不据此断言整个 App 组合已兼容，也不宣称整个 Avalonia 违法。独立 no-DNG Skia 资产不含 Avalonia，不受这一 App 组合项阻断，仍须满足自身的实际构建与交付审核。
