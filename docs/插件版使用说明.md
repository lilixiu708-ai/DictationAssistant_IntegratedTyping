# Windows 插件扩展版：使用说明

构建日期：2026-10-19。自定义构建标识：`0.0.0-plugins.1`。插件接口：v1。

本版本基于 ArcticLampyrid/DictationAssistant 的 4.x 源码及此前的随机顺序扩展制作，面向 Windows x64。它增加从本地插件目录加载文档提取器的接口，并附带独立的 Word 词表导入插件。主程序保留随机顺序、撤销及原有播报功能。

## 1. 第一次运行

1. 下载 `DictationAssistant_Plugins_Windows_x64.zip`，把整个压缩包解压到一个普通文件夹。
2. 打开解压后的 `DictationAssistant_Plugins_Windows_x64` 文件夹，双击 `DictationAssistant.App.exe`。
3. 完整程序包已放好 Word 插件，可以直接点击词表上方的“导入文档”。

程序包自带 .NET 10 运行组件；普通使用不需要另装 .NET SDK。请保留 EXE 旁边的 DLL、`Plugins` 及其他运行文件。此版本没有 Windows 发布者数字签名，也不是上游官方发布包。

原版程序及此前只有随机排序的版本不含这个插件接口。首次使用侧载功能，请使用本次完整程序包；单独把插件 DLL 复制到旧程序旁边不会增加接口。本次 Windows 包也不能直接替换此前的 macOS 应用。

## 2. 从 Word 提取听写词表

入口有三个：词表上方的“导入文档”、菜单“插件 → 从文档提取词表”、快捷键 **Ctrl+Shift+I**。普通“文件 → 打开”、拖放文件以及启动时传入一个文档路径也会使用相同的文件路由。

选择 `.docx` 后，先核对预览，再按“替换当前词表”或“追加到词表”。取消预览不会提交词表变更。

| 选项 | 用法 |
| --- | --- |
| 文档区域 | 可以选择某一张表、正文段落或所有表格。存在表格时，“所有表格”不包含正文标题、姓名和得分栏。 |
| 提取列 | 默认使用插件推荐列；可切换到英文、中文释义、词性等实际存在的列。 |
| 跳过表头 | 默认开启，排除插件识别出的表头。误判时可以关闭并手工校正预览。 |
| 去除完全相同的条目 | 默认关闭，保留有意重复的词条。开启后按整理后的文字精确比较，区分大小写，保留第一次出现的顺序。 |
| 移除行首编号 | 默认开启，处理 `1. word`、`2、单词`、`(3) phrase` 等明确编号。`3D model`、`21st century` 和小数不会因此去掉数字。 |
| 可编辑预览 | 可以直接增删、修改词条。改变筛选选项或重新读取会重新生成预览，替代手工修改。 |

一个选中的单元格形成一条词条。词组不会按空格拆成多个词；单元格内的换行、制表符和连续空白会整理成单个空格。选择多张表格并指定列时，按列序号匹配；不存在该列的行计入跳过数量。

### 本次“第二周听力词汇.docx”的结果

文档含两张相同词表，每张有 40 条记录及一行表头。第二张表的英文答案使用白色字体，文本仍保存在文档内。

| 选择方式 | 实际提取结果 |
| --- | ---: |
| 默认：表格 1、推荐的“单词”列、跳过表头 | 40 条英文词条 |
| 表格 1、第 4 列“中文释义” | 40 条中文释义 |
| 所有表格、推荐列、保留重复项 | 80 条英文词条 |
| 所有表格、推荐列、开启去重 | 40 条英文词条 |

默认结果不会导入独立的序号列、词性列和中文列。`Monday` 等星期和月份保持大小写，`ambiguous` 末尾的多余空格被清除。完整词表另附 `W02_听力词汇_英文.txt` 与 `W02_听力词汇_中文释义.txt`。

## 3. 导入后听写、随机排序和保存

1. 确认导入后，按需要选择中文或英文语音、播报间隔和重复次数。
2. 点击“打乱顺序”，或按 **Ctrl+Shift+R**；每次操作重新安排整条词语或短语的顺序。
3. 点击“开始播报”。也可以使用原有的手动上一条、下一条及再报一遍功能。

导入和打乱都会先等待旧播报流程结束、清零进度，再修改同一个词表编辑器。**Ctrl+Z** 可以一次撤销一次替换、追加或打乱；撤销追加会恢复此前的词表。

“保存”输出纯文本词表。导入 Word 后默认建议同名 `.txt`，例如 `第二周听力词汇.txt`；程序不会把文本写回作为输入的 `.docx`。保存入口会拒绝使用 Word 等非文本扩展名。TXT 可再次打开，或交给旧版程序使用。

随机顺序功能保留重复词条和原有空行；短语或句子按整行移动。全部词条相同或只有一条时，程序会提示无需打乱。

提取环节在本机读取文档，不要求安装 Microsoft Word。播报是否联网取决于原程序中选择的语音引擎；在线语音与本地语音沿用各自的运行条件。

## 4. 侧载、更新或移除插件

完整 Windows 包已经带有 Word 插件。单独的 `DictationAssistant_Docx_Plugin.zip` 用于给这个支持插件的主程序重新安装或更新提取器。

安装步骤：

1. 退出应用。
2. 解压单独的插件包，取得完整的 `DocxVocabulary` 文件夹。
3. 将它放在 EXE 同级的 `Plugins` 文件夹内，使清单路径为 `Plugins/DocxVocabulary/plugin.json`。
4. 重新运行程序，在“插件 → 插件管理”中确认“Word 词表导入”显示“已加载”。

重要文件的位置：

| 文件 | 相对于应用主文件夹的位置 |
| --- | --- |
| 主程序 | `DictationAssistant.App.exe` |
| 共享接口程序集 | `DictationAssistant.Plugin.Abstractions.dll` |
| 插件清单 | `Plugins/DocxVocabulary/plugin.json` |
| Word 提取器 | `Plugins/DocxVocabulary/DictationAssistant.Importers.Docx.dll` |
| 插件依赖描述 | `Plugins/DocxVocabulary/DictationAssistant.Importers.Docx.deps.json` |

不要只复制一个 DLL，也不要多套一层插件包文件夹。每个插件使用自己的第一层子文件夹。更新时退出应用，再用完整新文件夹替换旧版本；移除时退出应用，将对应子文件夹移出 `Plugins`。操作都在重新启动后生效，不支持运行中热替换。

“打开插件目录”可以定位安装位置。没有写入权限时，可把整套便携程序放在自己有写入权限的普通文件夹中使用。

第三方插件在应用进程中运行，拥有应用本身的权限；只安装可信来源的插件。插件管理会显示清单、接口版本、缺失依赖或入口类型等常规加载错误，一个加载失败的插件不会阻止其他有效插件加载。进程内接口不提供对恶意代码或崩溃插件的安全隔离。

## 5. 支持范围

- 附带提取器支持包含真实文字的 `.docx` 正文、表格和明确存储的白色或隐藏文字。
- 支持选择英文词语、短语、句子或中文释义等任意实际列；无表格的逐段文字也可预览导入。
- `.doc` 请先另存为 `.docx`。扫描图片、照片、PDF OCR、受密码保护的文档以及文档中嵌入对象不在这个插件的支持范围内。
- 不将页眉、页脚、脚注、批注和文本框作为正文词表导入。不读取图片文字，也不运行文档宏。
- 复杂合并表格、没有清楚表头的资料及一格多条词语需要在预览中核对；此版是一格一条的提取方式。
- Word 文件上限 64 MiB，正文 XML 解压后上限 32 MiB；其他结构上限见开发指南。输入超过限制时会显示错误。

本接口当前面向“文档提取器”。未来可按同一契约制作其他格式的插件；任意脚本、音频引擎替换、工具栏扩展不是当前 v1 接口提供的功能。

## 6. 开发者构建与批量提取

完整对应源码在 `source`。使用 `.NET SDK 10.0.402` 或 `global.json` 允许的兼容补丁版本，在 Windows PowerShell 中运行：

```powershell
cd source
./build-windows.ps1
```

程序输出到 `artifacts/Windows-x64`，独立插件输出到 `artifacts/DocxVocabulary`。编译器需要还原源项目的 NuGet 依赖。脚本不需要修改系统的 PowerShell 执行策略；如本机策略不允许脚本，可按开发指南中的 `dotnet` 命令手动构建。

已经安装 .NET 10 SDK 的开发者可以在程序文件夹使用：

```powershell
dotnet .\DictationAssistant.App.dll --list-plugins
dotnet .\DictationAssistant.App.dll --extract "第二周听力词汇.docx" --output "W02_英文.txt" --report "W02_提取报告.json"
dotnet .\DictationAssistant.App.dll --extract "第二周听力词汇.docx" --output "W02_中文.txt" --column 4
dotnet .\DictationAssistant.App.dll --extract "第二周听力词汇.docx" --output "W02_全部英文.txt" --section all
```

选项还包括 `--plugin ID`、`--deduplicate`、`--include-headers`、`--keep-numbering` 和 `--overwrite`。区域和列编号从 1 开始，默认使用推荐区域及推荐列。输出限定 `.txt`，报告限定 `.json`，默认拒绝覆盖现有文件。完整参数见 `--help`。图形 EXE 的控制台表现取决于启动方式，因此这里使用 `dotnet` 执行托管入口。

插件开发的完整接口、编译配置、示例和依赖规则见 [插件开发指南](插件开发指南.md)。单独 SDK 包含共享接口 DLL、XML 文档及可编译的 `.phrases` 示例。
