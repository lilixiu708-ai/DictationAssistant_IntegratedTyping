# 先读

首次安装或更新完整程序，请下载 [R5 本体](https://github.com/lilixiu708-ai/DictationAssistant_IntegratedTyping/releases/tag/v4.0.0-typing.5) 的 `*-win-x64-portable.zip`，完整解压后运行 `DictationAssistant.App.exe`。本体已包含两个插件，无需另装 .NET。

已有同系列宿主时，可按需下载[同步打字 1.1.0](https://github.com/lilixiu708-ai/DictationAssistant_IntegratedTyping/releases/tag/plugin-synchronous-typing-v1.1.0)或 [Word 导入 1.0.1](https://github.com/lilixiu708-ai/DictationAssistant_IntegratedTyping/releases/tag/plugin-docx-vocabulary-v1.0.1)的独立更新包，关闭程序后替换完整插件目录并重启。

操作和当前状态见[项目首页](README.md)，完整说明见[文档索引](docs/README.md)。源码包供开发使用，个人服务设置下载后在程序内完成。
